# 📚 Faculdade - Fila e Pilha

Este é um repositório mostrando o que aprendi na disciplina de Estrutura de Dados com o professor Fabiano, na Universidade Luterana do Brasil (ULBRA).

O repositório contém a implementação de filas, pilhas e programa de testes/exercícios, servindo como apoio para meus colegas de curso. Fico feliz em contribuir e mostrar meu aprendizado, e desejo a todos que acessarem este repositório sucesso em sua caminhada acadêmica e estudos.
